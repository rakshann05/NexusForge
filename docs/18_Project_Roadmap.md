# Project Roadmap

**Foundation (complete):** workspace scaffold, API boundary, Prisma model, security baseline, local stack, documentation.

**Collaboration core (next):** guarded organization/project/task APIs, functional board, wiki CRUD, migrations, and tests.

**Team intelligence:** Socket.IO activity/chat, analytics queries, notifications, optional AI adapters.

**Hardening:** accessibility audit, E2E suite, observability, object storage, deployment manifests, and production security controls.
