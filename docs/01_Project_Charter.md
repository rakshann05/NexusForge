# Project Charter

**Mission:** help software teams coordinate delivery and knowledge from one calm, self-hostable workspace.

NexusForge v0.1 establishes a secure multi-tenant foundation for organizations, projects, tasks, and knowledge. Success means a developer can run it locally, create a team workspace, and track meaningful work without an AI key or paid service.

## Constraints

Open-source dependencies, PostgreSQL, local storage in development, and optional AI only. The product must preserve tenant isolation and be deployable as independently scalable web and API services.
