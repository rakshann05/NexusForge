# Feature Specification

| Area | Minimum solid version | Expansion path |
| --- | --- | --- |
| Work management | Projects, statuses, priorities, assignees, ordered tasks | Sprints, dependencies, templates |
| Knowledge | Markdown documents per organization | Collaboration cursors, version history |
| Collaboration | WebSocket events and activity feed | Channels, mentions, notifications |
| Analytics | Project/task aggregate cards | Cycle time and custom reports |
| AI | Explicit optional provider interface | Retrieval, team controls, evaluations |
