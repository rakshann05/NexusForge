# User Flows

1. A user registers, creates an organization, and becomes its owner.
2. The owner creates a project, invites members, and adds tasks to Backlog.
3. A member moves work through To Do, In Progress, Review, and Done; subscribers receive a realtime event.
4. The team documents a decision in the wiki and links it from work.
5. An authorized user optionally enables an AI provider; unavailable providers return a clear feature-level notice.
