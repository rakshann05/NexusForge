# Product Requirements Document

## Goals

- Organizations can manage members and roles.
- Teams can create projects, organize Kanban tasks, and assign ownership.
- Teams can author searchable organization documents.
- Users receive safe, timely updates and basic delivery analytics.

## Non-goals for v0.1

Native mobile clients, source-code hosting, billing, and mandatory AI automation.

## Acceptance measures

Local startup succeeds with Docker PostgreSQL; non-members cannot read organization data; board updates persist; AI configuration absence does not affect core screens.
